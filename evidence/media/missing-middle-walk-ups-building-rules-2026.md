Low-rise apartments fell from **18%** of Sydney approvals in the early 1990s to about **1%**. The reforms aim for **112,000** homes in five years; **21%** of NSW's Accord target was built by March 2026; the government says 5,400+ homes have been approved.

## How the rules apply

| 3-storey walk-up | 30-storey tower |
|---|---|
| Type A fire construction at three storeys (NCC) | Type A at four or more storeys |
| Declared designs and compliance declarations for all Class 2 (DBP Act) | Same |
| Six months' notice before occupation (RAB Act) | Same powers apply |
| Practitioners can register in a medium-rise class | Needs a class without that height limit |
