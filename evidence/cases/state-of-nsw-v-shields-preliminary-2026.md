Mr Shields is on an extended supervision order expiring 23 December 2026. The State seeks a new two-year order in this civil-style, post-sentence proceeding.

## What the court decided

| Step | Held |
|---|---|
| Would the State's material, if proved, justify an order? | Yes |
| Experts | Two psychiatrists or psychologists appointed (s 7(4)) |
| Interim order | 28 days from expiry of the current order (ss 10A, 10C) |
| Conditions | Electronic monitoring and remote data inspection removed given his progress |
| Not decided | Whether to make the two-year order |
